# Synthetic Vehicle Fleet Telemetry

This repository is the **issue tracker** for the [Synthetic Vehicle Fleet Telemetry dataset on Hugging Face](https://huggingface.co/datasets/renumics/synthetic-vehicle-fleet-telemetry).

The dataset contains multivariate time-series data from carmaker simulations. Visit Hugging Face to explore the data, read the dataset documentation, and download the files.

## Report an issue or suggest an improvement

Use [GitHub Issues](https://github.com/Renumics/Synthetic-Vehicle-Fleet-Telemetry/issues) to report problems, ask questions, or suggest improvements to the dataset.

Before opening an issue, check whether it has already been reported. Include the relevant files or signals and, for bugs, steps to reproduce the problem.
